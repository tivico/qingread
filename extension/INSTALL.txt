清讀 0.3.9 · Windows 親友試用版

請將套件解壓縮到固定資料夾，例如 C:\QingRead，不要直接在 ZIP 內執行。
若從 https://github.com/tivico/qingread 取得原始碼，也可直接使用解壓後的專案資料夾，
其中 companion 與 extension 的操作方式相同；不需先找到另外的安裝 ZIP。
完整套件 qingread-complete-0.3.9.zip 包含外掛、本機助手與安裝腳本。
qingread-0.3.9.zip 只有外掛，適合已備妥新版助手或只使用 Chrome 語言包的人。

第一次安裝

1. 使用桌面版 Chrome 138 以上。
2. 需要本機模型翻譯時，從 https://ollama.com/download/windows 安裝並啟動 Ollama，
   再於 Ollama 下載一個本機文字模型。本套件不含模型，也不會自動選模型。
3. 需要本機助手時，雙擊完整套件 companion\install.cmd，等候安裝完成。
   它會準備專用 Python 環境；首次需要網路及數 GB 空間。
4. 雙擊 companion\start.cmd，使用本機功能期間保留助手視窗。
5. Chrome 開啟 chrome://extensions，啟用開發人員模式，按「載入未封裝項目」。
   完整套件請選 extension 資料夾；外掛專用包請選解壓後含 manifest.json 的資料夾。
6. 回到要翻譯的網頁，點 Chrome 工具列的清讀圖示，確認右上角 v0.3.9。
7. 使用本機功能時，開「PDF 與助手設定」→「連接本機助手」。
   核對助手確認視窗與畫面上的數字，按「是」；需要時可改用手動配對。
   自己的電腦可勾「記住這台電腦」，再選模型並按「使用這個模型」。
8. 要翻 PDF 或辨識語音，再按對應的資源下載按鈕，完成後才開始使用。

功能初驗

• 網頁提示需要允許網站時，在網頁翻譯狀態區貼上目前網址，核對「允許 網站名稱」後授權。
  經常換網站可到「設定」按「允許所有一般網站」，由 Chrome 確認；預設仍可逐站允許。
  跨網站授權會擴大可讀範圍，但仍只在按開始後擷取；可到 Chrome 的網站存取權改回點選時／指定網站。
  新入口需重新載入外掛、刷新網頁及重開側欄；不需重啟本機助手，舊安裝 ZIP 尚未含本批更新。

• 網頁：選正確原文語言，先按「測試引擎」，再翻一小段；確認可還原。
• 有字幕影片：開啟播放器原文 CC，選「讀取影片現有字幕」，再開始。
• 無字幕影片：準備好語音模型，回影片分頁再點工具列圖示，選「聆聽分頁音訊」。
  「同時顯示原文」可顯示字幕或辨識文字；按「收合側欄，繼續字幕」交給背景。
  直接關閉尚未交接的側欄會停止；停止後不應再顯示聆聽中。
• 影片摘要（新版原始碼）：開啟電腦版 YouTube 影片，到清讀「摘要」按「整理目前影片重點」。
  會自動尋找、展開及等待逐字稿，不需先手動開啟；支援新版「字幕記錄」及舊版。
  若逐字稿有搜尋條件，請先清空；等候超過三十秒會提示，可停止後重新整理影片再試。
  需本機助手與文字模型；會分段顯示，最後整合總覽，可點時間回看或複製。
  預設「精簡重點」較快，想保留較多文字可選「詳細整理」，兩者都讀取相同字幕。
  「查看摘要耗時」可看讀取原文、生成文字、載入及排隊時間。
  只整理讀到的字幕，不保證全片、不分析畫面。關閉側欄會停止未完成摘要。
  若提示助手需要更新，先等重要工作結束再重啟 start.cmd、重載外掛及刷新影片。
  既有 0.3.9 ZIP 未重新打包，這項功能目前僅在更新後的原始碼中提供。

從舊版更新

新版原始碼的 start.cmd 已加入啟動檢查：相同助手直接沿用，有更新且沒有工作時才交接。
第一次從不支援交接的舊助手升級，請先停止字幕、等工作結束並關閉原助手一次，再開 start.cmd。
如果原助手在背景，請依 README／維護紀錄核對該安裝位置的 app.py 程序；不要結束所有 Python。
關閉顯示錯誤的啟動視窗，不會關閉先前已在背景執行的助手。新版提示可顯示已核對的背景 PID
與啟動時間；先停止工作，再到工作管理員「詳細資料」依 PID 處理，未核對成功時不猜程序。
有進行中工作、其他安裝位置或配對不符時不會強制停止。原配對與模型設定保留。
重新載入外掛後，進「PDF 與助手設定」按「重新檢查連線」，依「準備檢查」逐項處理。
這批新啟動流程目前僅在原始碼，既有 0.3.9 ZIP 尚未重新打包。

1. 等重要工作結束，停止字幕並關閉舊助手；自行保留一份舊版程式以便回復。
2. 用完整套件的新程式更新原本的安裝位置，保留 companion\data 與 companion\.venv。
   不要把自己的 data、配對碼、文件或 .venv 複製給親友。
3. 在原本的 Chrome 清讀項目按「重新載入」，避免另外載入第二份同名外掛。
4. 重開 companion\start.cmd，刷新原網頁並重開側欄，確認外掛與助手均為 0.3.9。
5. 若助手無法啟動或提示依賴缺少，重新執行 install.cmd；通常不用重下載既有模型。

遇到問題

• 無法擷取聲音：刷新影片後再點工具列清讀圖示；允許音訊權限，並停止其他擷取。
• 助手忙碌：最多短暫等候約十秒；仍忙碌會停止並提示，先讓前筆工作收尾再開始。
• 收合失敗顯示「已恢復側欄」：保持側欄開啟，等重新收集音訊後繼續。
• 無法確認背景狀態：重新開啟側欄查看並先停止背景，再重試。
• 回復舊版：先停止工作，還原同一版的外掛與助手程式，保留自己的 data，重載並重啟。
