清讀 0.3.8 — 本機功能預覽版

0.3.8：摘要改為精簡輸出與逐步顯示；相同原文與模型的近期完整摘要可直接重用。
只靠 CPU 跑大型模型，首次讀取長文仍可能較慢；未下載或切換模型。
需重新啟動新版助手；手動配對仍在備用區。Chrome 重啟或外掛更新後，再按連接確認即可。
若顯示未授權，按「允許此網站」後到 Chrome 拼圖選單確認；也可直接點工具列清讀圖示，再整理摘要。
更新時關閉側欄、在 chrome://extensions 重新載入清讀，再開啟側欄確認 v0.3.8。
已具摘要功能的 0.3.4 助手可繼續使用，這次顯示修正不需重裝模型或重啟助手。

0.3.4 修正：語言辨識只讀可見正文，切換分頁或停止會取消；單字解釋不再沿用舊滑鼠位置。
PDF 先檢查頁碼範圍，取消排隊工作不啟動處理。更新後請重啟助手、重載外掛並刷新網頁。

本版新增文字翻譯：選「文字翻譯」，貼上原文後按「翻譯文字」，可複製、停止或清空。
修正影片已開啟卻被誤認為沒有影片網頁的問題。
更新後重新整理 YouTube，開啟播放器原字幕，再按「開始字幕」。
若顯示存取權問題，按「處理此網站的存取權」依提示授權後，回影片字幕重試。

1. Chrome 開啟 chrome://extensions，開啟開發人員模式。
2. 「載入未封裝項目」選取含本檔與 manifest.json 的資料夾。
3. 開一般外文網頁，點工具列清讀圖示，選來源及翻譯引擎。
4. Chrome 語言包可單獨使用；PDF、本機模型、語音辨識需本機助手。
5. 助手首次執行 companion/install.cmd，之後 start.cmd。另需 Ollama 與本機文字模型。
6. 側邊欄「PDF 與助手設定」貼上助手配對碼，選模型、準備資源。
7. PDF 先試 1–2 頁；影片先開原字幕，無字幕才啟用語音模式。

沒有付費翻譯 API。首次資源下載需要網路與磁碟空間。
PDF 原檔、譯本與快取會暫存於 companion/data/jobs，請使用工作列表清除。
配對碼只供自己的外掛，不要填入網站表單或提供他人。
影片擷取可能有延遲或略過片段；跨來源播放器與保護內容不保證支援。
PDF 引擎 BabelDOC 與沉浸式翻譯有關聯，本工具使用其本機開源套件。
這不是商店正式版；全新安裝、真實網站音訊與親友硬體尚需驗收。
完整資料流程、維護、測試、限制與來源見完整套件 README.md 和 THIRD_PARTY.md。



0.3.3 更新：關閉舊側邊欄，重新載入外掛，再重新整理網頁。
重開清讀須看見右上角 v0.3.8；看不到表示仍是舊畫面／副本。
不確定載入位置時，先停用舊清讀，再載入本資料夾，避免兩份同名外掛。
先按「測試引擎」，再按開始；錯誤會標明引擎啟動／網頁讀取／翻譯步驟。
詞彙表位於「設定」，影片操作位於「影片字幕」。

0.3.3 網頁授權修正：更新後關閉側欄、重新載入外掛、重新整理網頁，直接點工具列清讀圖示。
若仍讀取失敗，按「允許此網站」，到 Chrome 拼圖選單確認允許，再按開始翻譯。
確認後 Chrome 會記住該網站授權，可在清讀詳細資料的網站存取權撤回。
可選網站範圍不等於安裝時取得所有網站權限；本程式只以目前分頁提出授權請求。

0.3.3 閱讀排版：預設文章正文，Wikipedia 排除目錄、外觀控制、資訊框與參考資料。
譯文改為原文下方的細線文字。更新後務必重新整理網頁，才會替換已注入的舊版程式。
要翻被排除的資訊框等文字，請反白並選「只翻譯反白文字」。

0.3.3 修正 Skilljar 課程正文誤選頁尾 FAQ；一般網站改檢查正文容器可見性。
更新後重新整理原課程頁再翻譯；沒讀到正文時可先反白指定文字。

0.3.3：Skilljar 問答請先展開，再按開始翻譯；新展開的答案可再次按開始補翻。
已收合答案不讀取、不自動展開；譯文跟著原問答收合。

0.3.3：修正 Skilljar 課綱固定列高重疊；新增網頁摘要（本機助手必要）。
更新外掛並刷新網頁；摘要需重新啟動新版 companion/start.cmd，必要時重新配對。
摘要只涵蓋目前頁面前 6,000 字元，超限會標示部分內容。

0.3.3：能辨識網址時，「允許」按鈕直接請求該網站權限，確認讀取程式可載入後再開始。
若是檔案載入／頁面切換問題，會顯示不同診斷，不再一律要求授權。

0.3.3：翻不到課文可展開「課文沒有翻到？」尋找內嵌來源，手動另開分頁翻譯。
此功能不是跨來源內嵌原地翻譯；只提供可見 iframe 的網址，不繞過登入與授權。
更新後務必重新整理原頁，清除舊的導覽列譯文。

0.3.3：新增「文字翻譯」頁籤，貼上文字即用所選引擎翻成繁中，不讀取網頁。
每次最多 6,000 字元，不保存歷史；翻譯中可切換分頁，關閉或隱藏側欄會停止。
